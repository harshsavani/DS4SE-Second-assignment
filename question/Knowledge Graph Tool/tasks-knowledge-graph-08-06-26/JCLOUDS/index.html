How the study works

1. Please consider the instructions video and the linked instructions document. Make sure you are running this on a screen with sufficient resolution and a supported browser.

2. You will be presented with a sequence of tasks. The first task will be a tutorial task.

3. Please consider the presented information carefully.

4. Each task is split into multiple questions. For each question, provide your answer depending on the presented information.

5. For each question you will be asked to provide a rating on the information relevancy.

6. At the end of each task, there will be two questionnaires

7. At the end, upload the user study data on the PANDA course.

Study Complete

Thank you for participating. Please download the data file and save it for your records. You will be asked to submit this file via the PANDA course.
